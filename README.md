# AI Creative Classifier

Програмна система для автоматизованої класифікації рекламних креативів на основі зображень та відео.

Проєкт підготовлено для демонстрації результатів бакалаврської дипломної роботи на тему:

**«Система автоматизованої мультимодальної класифікації рекламних креативів на основі аналізу зображень та відео»**

Автор дипломної реалізації: **Ілля Парненко**.

## Призначення

Система перетворює неструктуровані рекламні матеріали у структурований результат, придатний для подальшого аналізу.

На вході система використовує:

- посилання на рекламні креативи;
- банерні зображення;
- відеокреативи.

На виході формується звіт із полями:

- `Link` — посилання на креатив;
- `Status` — статус обробки;
- `Product` — результат класифікації у форматі `Brand || Product || Category`.

## Структура проєкту

Проєкт складається з двох основних модулів:

1. `AdrealDownloadCreative` — модуль вивантаження креативів.
2. `Ads_AI-Classification` — модуль класифікації креативів.

Модуль вивантаження приймає список посилань, завантажує доступні рекламні матеріали, створює файл `output.txt` і теку `Creatives_YYYY-MM-DD`.

Модуль класифікації працює через графічний інтерфейс, обробляє зображення та відео, шукає дублікати, використовує історію попередніх класифікацій, звертається до API мультимодальної моделі та формує звіт у папці `Reports`.

## Основні можливості

- завантаження рекламних креативів за списком посилань;
- окрема обробка банерів і відео;
- представлення відео через вибрані кадри;
- пошук дублікатів і схожих креативів;
- використання історії класифікацій;
- класифікація нових креативів через API;
- формування підсумкового CSV-звіту.

Для роботи модуля класифікації потрібен API-ключ.

У публічній версії репозиторію реальний ключ не зберігається. У конфігураційному файлі має бути залишена тільки заглушка, наприклад:

```python
api_key = "PASTE_YOUR_API_KEY_HERE"
```

Перед локальним запуском користувач може вручну вставити власний API-ключ у конфігураційний файл.

## Запуск

### 1. Встановлення залежностей

Для кожного модуля можна окремо встановити залежності з відповідного файлу `requirements.txt`.

Приклад:

```bash
pip install -r requirements.txt
```

### 2. Вивантаження креативів

У папці `AdrealDownloadCreative` потрібно створити або змінити файл `links.txt`, додати до нього посилання на рекламні матеріали та запустити `RUN.bat`.

Посилання в `links.txt` додаються по одному з нового рядка та матимуть такий вигляд:
```txt
https://adreal.gemius.com/ua/show/<id1>
https://adreal.gemius.com/ua/show/<id2>
https://adreal.gemius.com/ua/show/<id3>
https://adreal.gemius.com/ua/show/<id4>
...
```

Після завершення роботи створюються:

- `output.txt`;
- тека `Creatives_YYYY-MM-DD`.

### 3. Класифікація креативів

У папці `Ads_AI-Classification` потрібно запустити модуль класифікації через `RUN.bat`.

Після запуску відкривається графічний інтерфейс, у якому потрібно вибрати теку з креативами та файл `output.txt`, після чого запустити класифікацію.

Результати зберігаються у папці `Reports`.

## Статуси обробки

| Status | Значення |
|---|---|
| `0` | Креатив не вдалося завантажити, тому класифікація не виконувалась |
| `1` | Креатив успішно завантажено і класифіковано |
| `2` | Креатив завантажено, але файл для класифікації не знайдено або обробку не завершено |

## Дані, які не входять до публічного репозиторію

- реальні API-ключі;
- реальні рекламні креативи;
- реальні посилання на креативи у файлі `links.txt`;
- файл `output.txt` з реальними результатами вивантаження;
- історія класифікацій;
- згенеровані звіти;
- службові файли середовища розробки.
